# Case Study: Regulated Consumer Goods — Age-Gated Commerce & Data Platform

## Overview
Role: Technical Architect | Duration: Sep 2020 – Present | Industry: Tobacco / Consumer Goods
Team: 10+ developers

## Challenge
Build and maintain a compliant age-gated eCommerce platform for a regulated consumer goods manufacturer, while also developing a data engineering platform for product, compliance, and sales analytics.

## B2C eCommerce Platform
- Enterprise Magento 2 / Adobe Commerce
- Age-gated compliance eCommerce with strict verification
- AWS: EC2, RDS Aurora, S3, CloudFront, VPC
- Caching: Redis, Varnish, Fastly for sub-2-second loads
- CI/CD: Azure DevOps with blue-green deployments
- Cut incident response time by 60%

## PACE Data Engineering Platform
- Hands-on Databricks notebooks and data workflows
- Built Spark-based ETL pipelines to transform product, compliance, and sales data
- Data stored in Delta Lake tables feeding the application layer
- Databricks Jobs for orchestration
- Unity Catalog for data governance and access control

## Technologies
Adobe Commerce, Magento 2, AWS (EC2, RDS, S3, CloudFront, VPC), Redis, Varnish, Fastly, Azure DevOps, Databricks, Spark, Delta Lake, Unity Catalog
